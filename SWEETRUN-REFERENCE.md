## What SweetRun Is

A maple syrup production platform for serious sugarmakers. Offline-first PWA (Progressive Web App) — no backend, no database, no cloud sync. Everything runs in the browser. One-person project by Damian Brockway.

- **Pricing:** $49.99/year subscription, 14-day free trial
- **Target audience:** Maple producers from hobbyists to large operations (under 100 taps up to 1,000+)

## Where the Code Lives

### GitHub Repository
- **Location on your Mac:** `~/Documents/GitHub/SugarCalc`
- **Remote:** GitHub (push with `git push` from that folder)
- **Main branch:** `main`
- **Auto-deploys to:** Cloudflare Pages on every push to main

### Key Files
| File | Purpose |
|---|---|
| `index.html` | Marketing landing page — the main sweetrun.app page |
| `feedback.html` | Feedback form for producers |
| `app/index.html` | The app shell — loads the compiled React app |
| `app/src/app.jsx` | React source code — **edit this, not app.js** |
| `app/app.js` | Compiled output — generated by `npm run build`, do not edit manually |
| `app/sw.js` | Service worker — handles offline caching. Current cache: `sweetrun-v3` |
| `sitemap.xml` | Submitted to Google Search Console |
| `package.json` | Build config — `npm run build` compiles app.jsx → app.js |
| `babel.config.json` | Babel preset (React JSX transpiling) |
| `SWEETRUN-REFERENCE.md` | This file |

### Build Process
When you update the app (app/src/app.jsx), you must compile before pushing:
```bash
cd ~/Documents/GitHub/SugarCalc
npm run build          # compiles app/src/app.jsx → app/app.js
git add app/app.js app/src/app.jsx
git commit -m "your message"
git push
```
Cloudflare Pages also runs `npm run build` automatically on each deploy as a build command, so pushing the source file alone will also work once Cloudflare Pages is configured to do so.

For landing page / feedback.html changes (no compile needed):
```bash
cd ~/Documents/GitHub/SugarCalc
git add index.html feedback.html   # or whatever files changed
git commit -m "your message"
git push
```

**Note:** If you get a `HEAD.lock` or `index.lock` error, run:
```bash
rm ~/Documents/GitHub/SugarCalc/.git/HEAD.lock
```

## Service Worker / Caching

The app uses a service worker for offline support. Current cache name: `sweetrun-v3`.

**File:** `app/sw.js`

If you update the app and users are seeing an old cached version, bump the cache version:
```javascript
const CACHE = 'sweetrun-v4';  // increment this number
```
Then commit and push. Users will get the fresh version on their next visit.
